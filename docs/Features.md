# Features

[Index](Index.md)

Non-technical description of what TaskBase does.

- View the task list, loaded from the API on page load.
- Add a task by typing a title and using the `+` button.
- Mark a task as done with a checkbox; done tasks are shown struck through and grey.
- Delete a task with the trash icon.
- Loading spinners inside the buttons while requests are in flight.
- Inline error message when a request fails.
- Material-style UI: cards, rounded corners, Google blue accent (`#1a73e8`).

Planned but not implemented:
- Persistence across restarts (currently in-memory).
